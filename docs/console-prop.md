# Console beside the TV

Super Retro Game Console by ELIZION: https://sketchfab.com/3d-models/super-retro-game-console-d672d0ac1d6a4d238314d6675f8f92b2

Source files: user-supplied 1K and 4K GLBs, preserved in build/console-source. Both have identical geometry and embedded CC-BY-4.0 attribution. Preparation uses the 1K download, which remains legible in the isolated close-up at a larger on-screen size than ordinary play. The 4K version offers little practical benefit for this small prop and would use 16 times the texture memory before downsampling.

Run scripts/prepare-console.gd with the Godot editor executable to regenerate build/console/console.scn and manifest.json. The source hashes are recorded. Remove the controller body/buttons and fully hidden underside fittings; retain the visible shell, switches and ports. Result: 8,527 triangles, one surface/material and three 1K BC7 textures with mipmaps, approximately 4 MiB GPU texture memory. The original atlas is preserved; controller texture space remains unused. Authored occlusion is combined in linear light into the base colour for Compatibility rendering. No new shaders or live shadows are added.

scripts/rendering/console_prop.gd places the console on the left of the TV, within the unchanged table bounds, with a slight angle. Two six-sided static cable meshes route video behind the TV and power behind the table. Console/cables inherit the same fade, scaling and placement as the TV. Contact shading is regenerated by scripts/rebake-room.ps1, whose geometry export includes the new prop/cables automatically. Future static props should be added before rebaking. Baked manifests record console presence so an old empty-table bake is not applied silently.

Windows and Linux exports include only the prepared scene, manifest and this notice in assets/console. Source downloads and isolated review images are excluded. THIRD_PARTY.md carries attribution and a modification notice. tests/console_prop.gd checks geometry, texture size/filtering, clearances, support and cable budgets; its image capture contains the CC-BY console alone and never the CRT model.
