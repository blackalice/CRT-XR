# Music visualiser

Expand the Music panel and select **Visualiser**, immediately to the right of **Browse albums**. The visualiser plays on the CRT, using existing local MP3 or radio playback. It pauses the previous game/video; B or Escape opens the menu while retaining the visualiser. Select Visualiser again to return with one press; Audio > Visualiser > Stop visualiser restores the previous programme. Opening the menu does not stop music. A or Space controls music playback; left/right selects a preset. The on-screen controls reuse the video transport panel and controller glyphs, and Audio > Visualiser uses the shared preset selector, toggle and brightness slider. Up/down adjusts brightness and Y toggles automatic changes. These preferences and the selected preset persist without automatically starting playback. Three original MIT presets are bundled. They change every 30 seconds unless reduced motion is enabled. User preset import is deferred.

The projectM renderer runs on an isolated native thread/context at 640x480, capped by 30 Hz submissions, with one latest-frame slot and one bounded stereo audio slot. Both eyes share the same texture. The capture is appended to the dedicated music bus so existing panning/reverb effect indexes remain stable. It follows music volume and room effects. The capture never changes audible audio routing. Pausing holds the last picture; unavailable libraries produce an explanation without disrupting music.

Build projectM using `scripts/build-projectm.sh windows` / `linux` and rebuild the native emulation extension. Full notices, the pinned source revision, and the offscreen patch are in `third_party/projectm`. Both export scripts copy the replaceable shared library and corresponding source materials outside the PCK. Linux requires OpenGL development libraries at build time.

Validation: `tests/music_visualizer.gd` checks controller order, native rendering, TV source ownership, preset selection and capture cleanup. Run with a real display/audio driver to verify visible audio-reactive pixels. Steam Deck hardware performance and long-session checks remain required before release.
